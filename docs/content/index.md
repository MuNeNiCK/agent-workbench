# Agent Workbench documentation

This documentation is for a project user who delegates coding work to Codex, Claude, or another
agent. You do not need to prepare a Workbench design document, operate its JSON interface, or install
Lean yourself.

## Start here

- [Installation](installation.md) — install the Skill and understand the files added to a project.
- [Getting started](getting-started.md) — make the first request and understand the response.
- [Everyday workflow](workflow.md) — correct, interrupt, resume, hand off, verify, and complete work.

## Understand the behavior

- [Concepts](concepts.md) — the public terms that may appear in agent reports.
- [Reviews](reviews.md) — when review is useful, what fresh/resume mean, and who decides findings.
- [Lean and assurance](assurance.md) — what a Lean receipt establishes and what remains evidence.
